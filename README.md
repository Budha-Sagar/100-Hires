# Small Issue I Faced

While pushing the repository to GitHub, I noticed the local branch was not created yet because there was no initial commit.

I solved it by:
```bash
git add .
git commit -m "Initial commit"
git branch -M main
git push -u origin main
```

This helped me better understand the GitHub push workflow and branch setup process.
